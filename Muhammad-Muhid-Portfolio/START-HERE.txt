MUHAMMAD MUHID - PERSONAL PORTFOLIO
=================================

QUICK PREVIEW
Open Muhammad-Muhid-Preview.html in Chrome or Edge. Scroll through the page.
React, GSAP, the photo, and downloadable resume are included inside this file.

LIVE ON VERCEL (same process as House of Icons)
1. Open https://vercel.com/drop and log in.
2. Drop the SITE folder - the folder containing index.html directly.
3. Use a project name such as muhammad-muhid-portfolio, then Deploy.

Do not drop the entire complete-project directory or the SOURCE folder.
The separate Muhammad-Muhid-Vercel-Upload.zip contains ONLY deployable files.
Extract it and drop its extracted folder into Vercel Drop.
Keep assets/, images/, vendor/, favicon.svg, and the resume PDF together.

EDITABLE REACT CODE
source/src/content.js  -> Your details, projects, experience, skills, contacts
source/src/App.jsx     -> Components and section layout
source/src/styles.css  -> Colors, layout, responsive styling
source/src/motion.js   -> GSAP timelines, pinning, reverse scroll, motion control
source/public/        -> Your photo, resume, and local animation libraries

To run the editable project: open a terminal in source/, then:
  npm install
  npm run dev

To rebuild: npm run build
Upload the files INSIDE source/dist/ after rebuilding.
The source README explains the small portable React build in full.

CONTENT
Your name, role, experience, projects, tools, education, achievements and contacts
are based on your supplied resume. Your original photo and PDF are unchanged.
LinkedIn could not be read; only the supplied profile link is included.
Project diagrams are labelled illustrations, not confidential production screenshots.
Email/phone links work through the visitor's apps. There is no fake form backend.
